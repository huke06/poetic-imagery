

1.获取appkey 和secret  登录 https://openapi.artlib.cn/index 注册用户获取 appkey 和 secret  2.Api 接口基础地址：  https://openapi.artlib.cn   后续的请求地址前需要加上该基础地址  3.获取token  请求地址：/get_token  请求方法：GET  请求参数：  参数  是否必填  类型  appKey  string  说明  secret  appKey  是  是  string  secret

开放艺术数据接口说明  每个Api接口都需要在 header 传入 token 参数 

## 接口基础信息

请求路由：`/work/detail/:id`

请求方法：`GET`

## 请求参数表

表格

| 参数 | 是否必填 | 类型   | 说明      |
| :--- | :------- | :----- | :-------- |
| id   | 是       | string | 艺术品 id |
